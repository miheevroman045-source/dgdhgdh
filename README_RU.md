# UltraEnchant Million 2.0.1 — Fabric 1.20.1

Мод для Minecraft Java с командами снятия ограничений на **записываемые** уровни зачарований и на совместимость чар с предметами. Поддерживает до 9 223 372 036 854 775 807 (signed 64-bit `long`) в собственной записи уровня на предмете.

## Команды (в одиночной игре доступны без читов; на сервере нужен OP)

Введи `/ue`, чтобы проверить регистрацию и увидеть подсказку. Затем возьми любой предмет в основную руку:

- `/ue add minecraft:multishot 1000000` — Multishot 1 000 000 на любом предмете
- `/ue add minecraft:sharpness 1000000` — Sharpness 1 000 000 на любом предмете
- `/ue all 1000000` — все зачарования сразу, включая проклятия
- `/ue shots 100` — устанавливает до 100 реальных снарядов за залп (по умолчанию 33; максимум 256)
- `/ue clear` — убрать наложенные чары, включая кастомный уровень

Истинный уровень хранится в `UltraEnchantLevels` как NBT Long. В обычном тегe `Enchantments[].lvl` находится уровень до 32767 (ограничение NBT short), из-за чего на подсказке показываются одновременно ванильное название и строка `[UltraEnchant] Мультивыстрел 1000000`.

## Важное различие: уровень ≠ количество летящих стрел

Ванильный Multishot делает 3 стрелы вне зависимости от уровня. В моде есть отдельная механика веерной стрельбы для метательных предметов и стрел. Ради защиты игры, реальных снарядов по умолчанию до 33, а команда `/ue shots` допускает максимум 256. **Мод не создаёт миллион реальных стрел**. Он может записать уровень 1 000 000, но эффекты других ванильных чар не всегда масштабируются до такого уровня (для этого потребуются отдельные правки каждого эффекта).

## Как собрать на GitHub бесплатно

1. Создай пустой репозиторий, например `UltraEnchantMillion`.
2. Распакуй архив проекта, загрузи **содержимое папки** проекта в корень репозитория. Убедись, что `build.gradle`, `gradle.properties`, `settings.gradle` и `src/` лежат в корне.
3. В GitHub создай файл `.github/workflows/build.yml` и вставь код из файла в проекте (скрытые папки иногда не загружаются через сайт).
4. Открой Actions → Build UltraEnchant Million → Run workflow.
5. После успешной сборки скачай `UltraEnchant-Million-Fabric-1.20.1` из раздела Artifacts. Внутри будет `ultraenchant-2.0.1.jar`.
6. Установи Fabric Loader + Fabric API для Minecraft **1.20.1**, положи JAR мода в `.minecraft/mods`.

При ошибке GitHub Actions открой упавший шаг **Build mod** и отправь полный лог.

## Сборка локально

Java 21, Gradle 8.12.1: `gradle clean build`.

## Совместимость

Только Minecraft 1.20.1 Fabric. Не подходит для версии Minecraft 26.3. Исходники не компилировались в этом окружении из-за отсутствия Gradle и доступа к зависимости Minecraft/Fabric. Поэтому для готового JAR необходимо запустить GitHub Actions; успешная сборка пока не подтверждена.
